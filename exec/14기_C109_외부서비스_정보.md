# 외부 서비스 연동 정보 정리

본 문서는 프로젝트에서 사용하는 외부 서비스(소셜 인증, 클라우드 저장소, AI 게이트웨이, 영상통화 등)의 가입/설정/운영에 필요한 정보를 정리한다.

## 1. 소셜 인증 (OAuth2)

### 1-1. Google OAuth
- 용도: 사용자 소셜 로그인
- 필요 정보
  - Client ID
  - Client Secret
- 프로젝트 환경 변수
  - `GOOGLE_CLIENT_ID`
  - `GOOGLE_CLIENT_SECRET`
- Redirect URI 패턴
  - `${DOMAIN_URL}/login/oauth2/code/google`
- 설정 위치
  - `backend/src/main/resources/application.properties`
  - `Jenkinsfile` (`.env` 생성)

### 1-2. Kakao OAuth
- 용도: 사용자 소셜 로그인
- 필요 정보
  - REST API 키(또는 Client ID)
  - Client Secret
- 프로젝트 환경 변수
  - `KAKAO_CLIENT_ID`
  - `KAKAO_CLIENT_SECRET`
- Redirect URI 패턴
  - `${DOMAIN_URL}/login/oauth2/code/kakao`
- 추가 Provider Endpoint는 `application.properties`에 정의됨

### 1-3. Naver OAuth
- 용도: 사용자 소셜 로그인
- 필요 정보
  - Client ID
  - Client Secret
- 프로젝트 환경 변수
  - `NAVER_CLIENT_ID`
  - `NAVER_CLIENT_SECRET`
- Redirect URI 패턴
  - `${DOMAIN_URL}/login/oauth2/code/naver`

## 2. 영상 통화 서비스

### OpenVidu
- 용도: 화상 상담 세션 생성/토큰 발급/미디어 연결
- 필요 정보
  - OpenVidu URL
  - OpenVidu Secret
- 프로젝트 환경 변수
  - `OPENVIDU_URL`
  - `OPENVIDU_SECRET`
  - `OPENVIDU_PUBLIC_URL`
- 관련 설정
  - 프론트 Nginx가 `/openvidu`, `/dashboard` 경로를 OpenVidu로 프록시
  - 파일: `frontend/nginx/default.conf`
- 참고
  - OpenVidu Browser SDK 버전은 서버 버전과 맞춰야 함 (현재 프론트 `2.30.0`)

## 3. 클라우드 스토리지

### AWS S3
- 용도: 이미지/파일 업로드 저장소
- 필요 정보
  - IAM Access Key
  - IAM Secret Key
  - S3 Bucket Name
  - Region (ap-northeast-2)
- 프로젝트 환경 변수
  - `S3_ACCESS_KEY`
  - `S3_SECRET_KEY`
  - `S3_BUCKET_NAME`
- 설정 위치
  - `application.properties` (`cloud.aws.*`)

## 4. 메일 서비스

### SMTP (Gmail 등)
- 용도: 이메일 인증/비밀번호 재설정 메일 발송
- 필요 정보
  - SMTP 계정
  - SMTP 비밀번호(앱 비밀번호 권장)
- 프로젝트 환경 변수
  - `MAIL_USERNAME`
  - `MAIL_PASSWORD`
- 기본 설정
  - host: `smtp.gmail.com`
  - port: `587`
  - STARTTLS 사용

## 5. 공공 데이터 API

### 유기동물 공공 API
- 용도: 유기견 데이터 수집
- 설정 위치
  - `application.properties`
- 설정 항목
  - `api.abandoned-dog.url`
  - `api.abandoned-dog.serviceKey`
  - `api.abandoned-dog.upkind`
  - `api.abandoned-dog.numOfRows`

## 6. AI 코드 컴파일/추론 관련 외부 연동

### GMS AI Gateway (SSAFY 제공)
- 용도: 임베딩/생성형 AI 호출 중계
- 필요 정보
  - API Key
- 프로젝트 환경 변수
  - `GMS_KEY`
- 설정 위치
  - `spring.ai.openai.*`
  - `spring.ai.vertex.ai.gemini.*`

## 7. 모니터링 외부 접근

### Grafana / Prometheus
- 용도: 운영 모니터링
- 접근 포트 (호스트 바인딩)
  - Prometheus: `127.0.0.1:9091`
  - Grafana: `127.0.0.1:3000`
- 참고
  - 외부 공개 시 보안그룹/리버스프록시/계정정책 별도 필요

## 8. Jenkins Credential ID 목록 (운영 등록 필요)
- `DB_ROOT_PASSWORD`
- `OPENVIDU_SECRET_KEY`
- `JWT_SECRET`
- `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`
- `KAKAO_CLIENT_ID`, `KAKAO_CLIENT_SECRET`
- `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`
- `MAIL_USERNAME`, `MAIL_PASSWORD`
- `AWS_ACCESS_KEY`, `AWS_SECRET_KEY`, `S3_BUCKET_NAME`
- `GMS_KEY`

## 9. 가입/설정 체크리스트
1. OAuth Redirect URI를 운영 도메인 기준으로 정확히 등록
2. S3 버킷 CORS/퍼블릭 접근 정책 점검
3. SMTP 계정 보안(앱 비밀번호, 발신 한도) 점검
4. OpenVidu URL/인증서 유효성 점검
5. Jenkins Credentials 등록 후 배포 파이프라인 dry-run 수행
