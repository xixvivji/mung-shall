## 2. Git Clone 이후 빌드/배포 절차

### 2-1. Clone
```bash
git clone <GITLAB_REPO_URL>
cd S14P11C109
```

### 2-2. Backend 빌드
```bash
cd backend
chmod +x ./gradlew
./gradlew build -x test
cd ..
```

### 2-3. Frontend 빌드
```bash
cd frontend
npm install
npm run build
cd ..
```

### 2-4. 도커 이미지/컨테이너 배포
```bash
docker build -t backend-image:latest ./backend
docker build -t frontend-image:latest ./frontend
docker compose up -d --force-recreate --remove-orphans mysql redis prometheus grafana node-exporter
docker compose up -d --force-recreate --build --remove-orphans backend frontend
```

## 4. 배포 시 특이사항
1. Jenkins 파이프라인은 `develop`/`master`에서만 Deploy 단계 수행.
2. Nginx(프론트 컨테이너)가 SSL 종료를 담당하며 인증서는 `/etc/letsencrypt`를 읽기 전용 마운트.
3. 백엔드/DB/Redis/모니터링 포트 다수는 `127.0.0.1` 바인딩으로 외부 직접 접근 차단.
4. OpenVidu는 docker-compose 내부 컨테이너가 아니라 외부 주소(`OPENVIDU_URL`)를 사용.
5. `docker image prune -f`가 파이프라인 마지막에 수행되므로 롤백용 로컬 이미지 정책 점검 필요.
